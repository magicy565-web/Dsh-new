安装之后怎么使用？

在 DSH Web 新建会话，选用「网站转杂志」预设，输入网站与目标读者。让 Agent 先核对来源，再编辑、设计与复核。若需要 Apify 采集，请先通过宿主配置相应 Token。

怎么确认下载包可信？

站点附带 构建清单与 SHA-256。目前仅是仓库构建产物，不代表已经通过你的目标电脑、模型、浏览器和实际网站的完整验收。不要在聊天或仓库中粘贴 API 密钥。

A focused sourcing product

这个插件会帮我自动找到采购商吗？

当前版本负责官网采集、英文编辑、HTML 设计和交付。买手挖掘、触达、回复追踪属于后续业务环节，本页面不冒充已经实现。

一定需要 Apify 才能生成吗？

如使用插件内置 Apify 网站采集工具，需要配置账户与额度。已有授权的本地资料也可以交由 DSH 原生文件工具读取后制作，但必须明确来源和素材使用权。

这是一个固定模板生成器吗？

不是。四项 Skill 指导当前模型直接编写 HTML/CSS/JavaScript。原有固定编译器仅作显式兼容用途，不作为主要创作路线。

安装完成就代表商业验证通过了吗？

不代表。安装和本地工程测试只能证明部分技术功能；真实采购价值需要来自真实企业与买手反馈。
