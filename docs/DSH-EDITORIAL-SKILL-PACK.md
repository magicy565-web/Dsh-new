# 四技能包与原生设计制作

2026-10-26，`dsh-buyer-magazine@0.3.0`。用户指出原产物只有通用工作稿，随后提供 `luxury_ecommerce_skills_package.zip`。这是一组四个协作技能，接入现有单一插件：

| 原始技能 | 实际职责 |
| --- | --- |
| ai-media-kinetic-commerce | 总编排、五跨页故事、交互与交付 |
| apify-ecommerce-intelligence | 真实品牌、商品、来源与图片采集 |
| editorial-magazine-design | Kinfolk / Loewe / Monocle / 032c 原型与跨页设计 |
| editorial-typography-system | CJK / Latin 字体、标题声部与字阶 |

ZIP 的全部 15 个原始文件按字节保留，含两份未执行的参考脚本。运行 SKILL 另加明确的 DSH 适配约定，原始正文和来源哈希可以核对。`buyer-magazine` 只作兼容入口；研究、编辑、设计、编译、看图修订和交付是六个流程阶段，不是另造六个技能。

## 同一宿主与编译器

DSH 继续提供模型、会话、网页读取、文件策略、附件和 official present。新增 web-card 是同一文档编译器内的五跨页组合。既有 Studio、十模块和 ERP 只读适配不再维护另一套渲染。

实际交互包括滚动/翻页、方向键、材料样本切换、图片放大、描图注记、品牌 vCard、真实联系链接或本地需求卡下载。不会提交模拟 Webhook。印刷版展开材料说明，并保留可读来源网址。

`buyer_magazine_review` 只接收规范 issue，渲染同一编译结果，通过原生图片附件让当前模型审阅。可检查 375/768/1440 宽度，以及完整桌面和手机跨页；PDF 使用实际 Chromium 输出和 pdfinfo/pdftoppm 页图。页面不允许任意浏览，仅通过宿主现有网络通道读取 issue 中的确切图片地址。返回 observed 只代表机械检查通过，不代表审美通过。

生成始终保留审阅稿标识；没有图片或设计说明时明确报告缺口，不把模板成功视为完成。用户提供的网站按本会话的自有/已授权声明处理，记录声明来源；自行选择的第三方测试站不会继承商用授权。

## 真实边界

FastAI 图片中继、Apify、VIP 核验和线索后端没有配置为本包工具。原站授权图片和原生网页读取可完成当前路径；需要外部服务的任务须报告实际缺项，不运行占位密钥脚本。视频不自动生成，无证据时不虚构 ROI。HTML 的图片仍引用来源 URL，需要网络；PDF 嵌入实际渲染图片。

运行依赖宿主模型、Chromium 和原生附件；PDF 页图还需 Poppler。独立指不依赖另一个业务插件，不意味着无需模型或网络。此轮不发布环境、不创建独立网站宿主、不迁移现有业务数据。
