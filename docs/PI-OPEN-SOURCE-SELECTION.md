# Pi open-source reuse review, 2026-10-13

The installed `@earendil-works/pi-agent-core`, `pi-ai`, `pi-durable` and `chord` package metadata identifies [earendil-works/pi](https://github.com/earendil-works/pi) as their source. The historical [badlogic/pi-mono](https://github.com/badlogic/pi-mono) URL currently redirects to this repository; it is not treated as a separate interchangeable SDK. The selected TUI is the same upstream's coding-agent `InteractiveMode`, rather than merely building a custom renderer on its TUI library.
