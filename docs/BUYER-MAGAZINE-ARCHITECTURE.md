# 买手微刊架构边界

用户在 2026-10-26 明确：通过对话创建微刊；资料来自用户电脑工作区或通过工单上传的服务器文件；交易动作搭配 ERP。

## 创建与生成

用户用对话说明读者、本期目的、资料范围和内容要求。Agent 读取资料，按技能完成编辑与版面设计，并直接编写作品文件。没有独立可视化编辑器或模块选择后台的开发需求。

DSH 负责模型、会话、工具与文件交付。用户随后明确纠正：四技能包必须驱动当前 LLM 自主研究、编辑、艺术指导和设计实现。LLM 用原生文件工具创作实际 HTML/CSS/JavaScript；插件负责真实 Apify 采集、浏览器截图、PDF 与原生附件。无需 issue JSON，也不能把五跨页固化成五个模板容器。

用户提供的四个技能及原始资源保持完整。旧 Studio 编译器和模块/ERP 适配仅用于明确的兼容输入；`legacyCompiler: true` 是显式选择，创意设计预设不提供旧生成工具。没有第二个应用宿主或 Agent 循环。

设计必须由真实内容支撑，文字编排、视觉叙事和读者信息增量需要模型实际看图并修订。原 Allbirds 模板产物已被用户否定，不代表设计合格。Apify 缺少凭据时明确报告，不能静默替换采集方式后宣称完成。

## 两种资料入口

| 入口 | 读取方式 | 来源记录 |
| --- | --- | --- |
| 用户电脑工作区 | 本地运行的 Agent 通过原生文件工具读取用户指定范围；云端执行时需要已经存在的本地接入、同步或上传能力 | 原文件名称、版本或读取时间、页码／表格位置 |
| 工单上传到服务器 | 根据当前用户及工单读取已上传附件，通过实际可用的附件接口交给 Agent | 工单号、附件标识、版本、文件内位置 |

云端工作区不是用户电脑。没有本地接入时，不能把用户电脑路径当成云端可读取路径。服务器附件读取也不能仅凭一个工单号就宣称成功；必须由实际接口返回当前任务可访问的文件。

产品资料、图片、报价、成本和历史销售均可来自这些文件。历史销售即使源于第三方工具的导出表，仍保留原始统计口径、期间、币种和估算标记。读取了文件不等于证明其中所有商业事实正确。

工单用于提交创建要求、关联上传资料和接收生成结果。当前不把工单扩建为客户关系或经营管理系统。

对外微刊只展示适合读者的资料和引用；内部电脑绝对路径、私有附件地址、工单访问凭据不直接写进 HTML。来源追溯信息可保留在任务工作区，公开引用使用可披露的文件名、版本及说明。

## ERP 交易边界

ERP 是报价、样品订单、采购订单、库存、独家供货权益和名额预留等交易状态的权威来源。

- 内容生成阶段可以使用工作区资料或工单附件中的商业条件，但文件中的库存或名额只是有时间的快照。
- 微刊中的交易入口指向已配置的 ERP 页面，或经实际 ERP 适配工具发起已获授权的操作。
- 实际锁定时由 ERP 核对权益、可用量和交易条件；只有 ERP 返回明确成功及对应业务记录，才可表示锁定成功。提交申请、超时或未知结果都不等于成功。
- 工单状态、微刊页面点击和本地 HTML 不承担订单或名额状态；也不维护第二套库存和交易账本。

用户随后要求开发简易 ERP，当前由 [dsh-mini-erp](../integrations/dsh/dsh-mini-erp/README.md) 提供单机交易核心：商品、买手、供货权益和预留／确认订单，复用 DSH 工具执行。其 SQLite 数据库是本试点的交易账本，微刊和工单不保存第二套交易状态。没有默认接入 Medusa。

## 已实现与待接入

已实现：四技能驱动的原生文件创作、真实 Apify Actor 调用工具、作品截图/PDF 审阅与附件交付。实际网站采集仍需绑定 Apify 凭据后验证成功 run。十模块、JSON 编译、计算与来源展示保留为显式兼容能力。

已有运行能力：DSH 原生文件／附件能力可读取其实际工作区和可用附件。这里尚未验收用户电脑工作区接入或用户所述工单上传接口。

已新增：简易 ERP 的原生查询、登记和订单工具。Agent 可读取真实登记记录、在已有授权下操作预留；当前仅支持可信经营者使用的本机工作区，不提供远程买手服务或多机器共享交易。

待接入：实际工单附件来源、用户电脑远程接入、买手身份和 ERP 交易网页。当前没有公网交易 URL，不能把 HTML 链接能力当作买手已可自行锁定。

后续开发围绕这些实际接入点推进。可视化微刊创建后台和通用资料管理平台均不属于本产品边界。简易 ERP 的新增范围以本次用户授权为限，不扩展财务、付款或物流。

用户进一步指定 ERP 按 Shopify Admin 式经营后台设计，与微刊对话创建分开。现有原生产品／资料能力的复用判断和统一商品主数据的前提见 [ERP 复用说明](ERP-REUSE.md)；当前未迁移数据或新增后台页面。
