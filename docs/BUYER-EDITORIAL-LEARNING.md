## 阅读了什么

从 15 个来源入口取得并抽读 12 份实质材料：7 份刊物／报告 PDF，5 个采购指南或资料组织网页。另两个只是发现入口，HKTDC PDF 返回 403，都未计入正文学习。查看了 12 个 PDF 页面上的标题、正文、图组、图注、比较表和供应商索引；没有声称读完全部刊物。

主要刊物是 Global Sources 面料采购指南与样品采购册、PERFORMANCE DAYS、Natural Fibres Insight、Textile Insights、California Apparel News Textile Preview，以及 Source Fashion 的采购报告。CBI、The Loop 和 Cotton Incorporated 作为采购信息组织的辅助材料。每份材料的范围、日期、URL 和文件指纹见 [来源登记](evidence/buyer-editorial-learning-20261027/source-manifest.json)；具体观察见 [阅读笔记](../integrations/dsh/dsh-buyer-magazine/skills/editorial-magazine-design/resources/buyer-publication-reading.md)。历史刊物只学习编辑方法，不把旧报价、供应商数据、认证或法规当成今天的事实。

## Burel 那版的问题

- 采购读者过宽，成品毯选品、面料开发、空间项目混用一条叙事。
- 单位换算压过产品选择，工厂沿革、参观核验和重复限制说明占据主文。
- 面料、成品毯、墙板放在同一价格表，注释并未让这种价值比较成立。
- 缺少产品—细节—应用的准确图文对应；场景静物无法替代产品资料。
- 说教式标题和警句较多；“小尺寸永远更贵”“报价差四成”等判断超出证据。
- 先前通过的是执行与技术检查，不能推出采购编辑合格。用户评价已补记到原作品文档与回执。

## 写回现有技能的改变

四技能和原生预设现在先要求阅读 [采购编辑标准](../integrations/dsh/dsh-buyer-magazine/skills/editorial-magazine-design/resources/buyer-publication-standard.md)。新增的是资源文件与编辑约定，没有新 Agent、渲染器或杂志模板。

工作顺序是：具体读者与采购阶段 → 选题和候选范围 → 完整 copy-deck → 文字评阅 → 自主设计 → 实际视觉审阅。标题、副题、导语、正文、图注各有分工。来源审计留在任务记录，产品识别、差异和下一步行动留在读者正文。原来的奢侈品视觉手法仍保留，但不再强制多字体、12:1 字号比、蜡封或计算器。

标准包含一份内部编辑量表；它是本项目的第一版评阅工具，不是行业认证，不替代用户判断。用户要求先学习时，原生预设明确止于阅读、文字练习和复盘。

## 实际练习与纠错

[12 项原创练习](../integrations/dsh/dsh-buyer-magazine/skills/editorial-magazine-design/resources/buyer-publication-exercises.md)覆盖选题／导语、产品短文、比较取舍、工厂介绍、栏目顺序、图注／询问，以及餐具品类迁移、单位口径、记者经历、渠道条款、手机编排和广告声明。D01 使用限定的真实资料摘要，其余是明确标注的编辑练习设定，不进入真实业务事实库。

沿用原生 DSH Session `session-f11fce84-b95e-483d-a893-f4f38cd5d078`，通过原生 UI 给同一 DeepSeek 模型布置练习；模型实际 read 资源，write 练习与复盘，present 文件。外层助手逐题评阅并给反馈，没有创建第二个模型客户端或 Agent 循环。记录见 [实际执行与评阅摘要](evidence/buyer-editorial-learning-20261027/execution.json)。

第一轮的关键失败包括：从旧会话带入题目外的具体款式；把“有染整环节”写成自有设施和外协优势；补造退货凭证、起算时间及索赔条件；给新品添加季节和色号。原生自评还漏检了部分错误。随后逐题修订，再对标题承诺、图注、字数、手机信息层级和复盘准确性进行定点校订。保留各版与反馈，不以覆盖原稿隐藏错误。

实际形成 12 题、3 个版本。最后一版仍有问题：D12 把“材料未提供”写成“尚未公布”；D05 把完整在售目录当作初筛前提；部分文案仍像研究计划。结果记为“第一批文字训练完成，有残留问题”，不宣称全题通过或已经达到正式刊物要求。这些问题已回写编辑规则；另外提供外层编辑参考，与模型原始输出分开，不能冒称模型自己已完成下一轮。

这批学习同时训练采购可读性和事实约束。不能把所有未知写成大片免责声明，也不能为了像刊物而添造产品、手感、成本或供货事实。原始资料不足时应缩小选题，并明确应补研究的产品资料。
