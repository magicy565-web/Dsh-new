# AI Worker：设计系统

> 适用范围：AI Work 移动端（右侧嵌入 App）与协作画布中的 Worker 节点 / Worker Studio。
> 继承：`ai-work.css` 现有的 DSW alias 变量与 `aw-*` 结构；画布侧与 `COMMERCE-CANVAS-DESIGN-SYSTEM.md` 共用状态色与 AI 类型色。

## 1. 设计原则

1. **人在前，机器在后。** 每个 Worker 都必须同时露出"谁维护"和"在哪运行"。这是本产品与普通 Agent 模板的唯一区别，也是全系统唯一的标志性元素：**维护者印章（MaintainerSeal）**。
2. **安静的白色工具。** 延续现有截图的中性白底、细线、大圆角外壳；不使用渐变、光晕、插画。
3. **数字要有出处。** 实心数字只用于 DSH 真实统计；维护者自述用浅色文字加「自述」标签；样本不足就写"样本不足"。
4. **一屏一个主按钮。** 主操作用墨色实心按钮，其余都是次要或文字按钮。

## 2. 颜色（共 5 个：3 个中性 + 1 主色 + 1 AI 识别色）

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--aw-bg` | `#FFFFFF` | `#141517` | App 外壳、卡片 |
| `--aw-layer` | `#F4F5F6` | `#1C1D20` | 页面底、分区、输入框 |
| `--aw-line` | `#E9EAEC` | `#2A2C30` | 边框、分隔线 |
| `--aw-ink` | `#1F2124` | `#ECEDEF` | 主文字、**主按钮底色**、选中 Tab |
| `--aw-ai` | `#6E5FE6` | `#A39BF5` | 仅用于"AI 运行时"识别：运行时徽标描边、Worker 节点色条 |

派生（不计入色数，由上面计算）：
- `--aw-muted`：ink 62% → 次要文字（对比度 ≥ 4.5:1）
- `--aw-ai-soft`：ai 10% → 运行时徽标底色
- `--aw-ink-on`：= `--aw-bg`，主按钮文字

状态色**直接复用画布系统的 tone**（green / blue / amber / red / muted），只出现在 `StatusMark` 与 `StatusBadge` 里，不用于大面积背景。

维护者没有专属颜色——人用真实头像表达，不用色块。

## 3. 排版

- 字体：沿用 `--dsw-font-family`（`-apple-system, "PingFang SC", "Segoe UI", sans-serif`）；ID、版本号、时间用 `ui-monospace`。
- 阶梯（字号/行高 · 字重）：

| 角色 | 规格 | 用于 |
|---|---|---|
| Display | 24/32 · 650 · −0.04em | 页面标题（工作 / 发现 / 助手） |
| Hero | 20/28 · 650 · −0.02em | 模板详情名称 |
| Section | 17/24 · 650 | 分区标题 |
| Title | 15/22 · 600 | 卡片、行标题 |
| Body | 14/22 · 400 | 说明、任务简述 |
| Meta | 12/18 · 400 | 维护者、时间、计数（最小字号） |
| Mono | 12/18 · 500 | `v3`、工单 ID |

- 数字一律 `tabular-nums`；中文段落行高 ≥ 1.55。

## 4. 间距、圆角、阴影、动效

- 间距：4 基准 → `4 / 8 / 12 / 16 / 20 / 24 / 32`；页面左右内边距 20。
- 圆角：`8` 徽章 · `10` 按钮、输入框 · `14` 卡片、列表组 · `18` 底部面板顶角 · `24` App 外壳（沿用）。
- 阴影：外壳 `0 10px 35px rgb(25 30 35 / 5%)`（沿用）；底部面板 `0 -8px 30px rgb(25 30 35 / 8%)`；卡片不加阴影，只用 1px `--aw-line`。深色模式全部改为 1px 内描边。
- 动效：推入 220ms、面板 240ms、按压 120ms；缓动 `cubic-bezier(.2,.8,.2,1)`；尊重 `prefers-reduced-motion`（改为淡入）。

## 5. 组件体系

### A. 身份
**`MaintainerSeal`（标志性元素）**
- 结构：运行时徽标（20px，圆角 6）与维护者头像（20px，圆形）重叠 6px，头像带 2px `--aw-bg` 描边；右侧文字「{维护者} 维护 · {运行时}」。
- 尺寸：`sm`（列表，20px）/ `lg`（详情，28px，文字两行：名称 + 认证级别）。
- 认证级别：邮箱 / 企业 / 实名，以文字后缀显示，不用对勾图标冒充"官方认证"。
- 维护者暂停接单时，头像降为 50% 透明并追加「暂停接单」。

**`RuntimeBadge`**：运行时 logo + 名称，`--aw-ai-soft` 底、`--aw-ai` 1px 描边；`other` 使用 `Bot` 线性图标。

**`WorkerAvatar`**：维护者上传的方形图标（圆角 12）；缺省时为 `--aw-layer` 底 + 分类图标（Lucide），不生成字母渐变头像。

### B. 发现
- **`SearchField`**：40px 高，`--aw-layer` 底，无边框；聚焦时 1px ink 描边。
- **`CategoryChips`**：横向滚动；选中为 ink 底 + bg 字，未选为 1px line 描边。
- **`WorkerCard`**：
  ```
  [Avatar 44]  名称 ............................ [v3]
               一句话（最多 2 行）
               MaintainerSeal(sm)
               ─────────────────────────────────
               已验收 23 · 验收率 91%     或   样本不足
  ```
  整卡可点；已雇用时右上角显示「已雇用」文字标签替代版本号。

### C. 模板详情（专家模板体验）
- **`WorkerHero`**：Avatar 64 + Hero 名称 + 一句话 + `MaintainerSeal(lg)`。
- **`StarterTaskCard`**：「可以直接让它做」——2×2 网格（窄屏单列）；标题 + 一行简述 + 右下角箭头。点击 = 雇用并带入该任务。这是与 Grok 专家模板最接近的部分。
- **`CapabilityList`**：两栏「会做」（动作标签）/「不会做」（固定：子委托、对外发消息、支付、共享凭证）。
- **`EvidenceStat`**：一行三格（已验收 / 验收率 / 交付中位时长），每格下方 Meta 注明「来自 DSH 记录」；样本不足时整行替换为一句话。
- **`DeclaredRow`**：维护者自述的响应时间与服务时段，Meta 色 + 「自述」徽章。
- **`VersionRow`**：`v3` mono + 日期 + 变更说明（折叠 2 行）。
- **底部 `PrimaryBar`**：「雇用到 {项目}」主按钮；已雇用时变为「新建任务」。

### D. 雇用与审批
- **`HireSheet`**（底部面板）：
  1. 标题「雇用 {名称}」+ 项目名
  2. **`ScopeToggleRow`** × N：每个能力一行开关，默认全开，至少保留一项
  3. 「维护者可以看到」说明块：任务说明、授权资料、交付物；看不到项目其他数据
  4. 预算上限（Grok 运行时固定为 0 并说明原因）
  5. 主按钮「确认雇用」；运行时未连接时禁用并列出原因
- 任务审批面板沿用现有字段，顶部增加「来自预置任务：{名称} · 模板 v3」。

### E. 运行与介入
- **`TaskRow`**（沿用）：新增维护者头像 16px 在 Meta 前。
- **`ReviewBanner`**：任务详情顶部，「维护者复核中」/「维护者已通过」，muted tone。
- **`EscalateButton`**：次要按钮「联系维护者」，仅在失败、待核对、被退回时出现。
- **`ThreadMessage`**：维护者消息左对齐带头像，业主右对齐；系统事件居中 Meta 文字。

### F. 维护者端
- **`QueueItem`**：待复核 / 升级请求，左侧类型图标，右侧剩余期限（mono）。
- **`TemplateStatusRow`**：模板名 + 状态徽章（草稿 / 审核中 / 已发布 / 已暂停 / 已下架）+ 已雇用项目数。
- **`DutySwitch`**：「接单中 / 暂停接单」大开关，切换需确认并说明影响。

### G. 画布 Worker 节点（扩展 `NodeCard`）
- 顶部 2px 色条使用 `--aw-ai`（与画布 AI 类型色一致）。
- 头部：WorkerAvatar 28 + 类型眉标「AI WORKER」+ 状态徽章。
- 标题下增加一行 `MaintainerSeal(sm)`；元数据行显示 `v3` 与最近活动时间。
- 可升级时节点右上角 6px ink 圆点；暂停时整卡 60% 透明。
- 紧凑版（zoom < 0.45）只保留头像 + 名称 + 运行时徽标。

## 6. 图标

Lucide，1.5px 线宽，16 / 20 / 24。固定映射：发现 `Compass`、助手 `UsersRound`、工作 `LayoutGrid`、预置任务 `ArrowUpRight`、复核 `ShieldCheck`、联系维护者 `MessageSquare`、暂停 `PauseCircle`、版本 `GitCommitHorizontal`、其他运行时 `Bot`。Grok / Muse 使用官方 favicon（见 `AI-WORK-CONNECTIONS.md` 来源说明）。

## 7. 无障碍

- 所有可点卡片是 `<button>` 或 `<a>`，`aria-label` 包含名称、维护者、运行时、状态。
- `MaintainerSeal` 的两张图都是装饰，文字承载信息。
- 状态从不只用颜色：圆点 + 文字。
- 底部面板打开时焦点移入并锁定，`Esc` / 返回关闭。
- 触控目标 ≥ 44×44；对比度正文 ≥ 4.5:1、图标 ≥ 3:1。
