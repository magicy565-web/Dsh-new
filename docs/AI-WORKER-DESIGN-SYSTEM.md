# AI Worker 设计系统 · 「工牌 Roster」

## 方向

AI Worker 是「被雇来的岗位」，所以视觉语言取自**工牌与花名册**：挂孔、挂绳色带、工号、署名。全系统唯一的标志性元素是 **Worker 工牌**；其余界面保持安静的工具感。Grok Bot / Muse 的品牌色只存在于它们的官方图标里，界面本身不借用。

## 颜色（5 个）

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--rs-bg` | `#EEF0F3` | `#0C0E11` | 页面底 |
| `--rs-card` | `#FFFFFF` | `#16191E` | 卡片、面板、工牌 |
| `--rs-ink` | `#11141A` | `#F1F3F6` | 文字、次要按钮描边 |
| `--rs-line` | `#DADDE3` | `#2A2F37` | 边框、分隔、挂孔 |
| `--rs-lanyard` | `#FF5A1F` | `#FF6B33` | 挂绳色：工牌色带、主按钮、选中 Tab、需要你确认的计数 |

派生：`--rs-muted` = ink 60%（次要文字，对比 ≥ 4.5:1）；`--rs-on-lanyard` = `#11141A`（主按钮文字用墨色，保证橙底对比）。状态用 文字 + 6px 圆点，圆点只用 ink / muted / lanyard 三种，不引入红绿。

## 字体（2 个）

- **Noto Sans SC**：标题 700、正文 400、标签 500。
- **Geist Mono**：工号、版本、价格、时间、计数（`tabular-nums`）。

| 角色 | 规格 |
|---|---|
| Display | 28/34 · 700 · −0.02em |
| Title | 18/26 · 700 |
| Row | 15/22 · 500 |
| Body | 14/22 · 400 |
| Meta | 12/18 · 400 |
| Mono | 12/16 · 500 · 0.04em 大写 |

## 间距与形状

- 4 基准：4 / 8 / 12 / 16 / 20 / 24 / 32；页面左右 20。
- 圆角：6 标签 · 12 按钮与输入 · 16 卡片 · 20 工牌 · 24 底部面板顶角。
- 工牌挂孔：顶部居中 36×8 圆角胶囊，`--rs-bg` 填充 + `--rs-line` 内描边。
- 阴影：只给工牌与面板 `0 1px 0 var(--rs-line), 0 12px 32px rgb(17 20 26 / 8%)`；深色模式改为 1px 描边。
- 动效：推入 220ms、面板 260ms、工牌入场从 8px 下方淡入，列表错峰 40ms；尊重 reduced-motion。

## 组件

| 组件 | 规格 |
|---|---|
| **WorkerBadge**（标志） | 竖版 20 圆角卡；挂孔；顶部 64px 挂绳色带内写 `AI WORKER · No.0231`（mono）与分类；色带下 Worker 图标 56 压在色带边缘；名称 + 一句话；署名区左右两栏「维护者」（头像 + 名字 + 认证）/「运行于」（官方 Agent 图标组）；底部虚线上方 mono 统计行 |
| **BadgeRow** | 列表用：左侧 4px 挂绳色竖条 + 图标 44 + 名称 / 一句话 / 维护者行 + 右侧运行时图标叠放与价格 |
| **RuntimeIcon** | 官方图标，20 / 28 / 40，圆角 = 尺寸 × 0.24；叠放时 −6px 并加 2px card 描边 |
| **MaintainerChip** | 首字母头像 20（ink 底 card 字）+ 名字 + 认证级别文字 |
| **StarterTile** | 「直接让它做」：14 圆角卡，标题 + 一行说明 + 右上 ↗；点击即招募并带入 |
| **ScopeRow** | 能力开关行；「不会做」列表为灰色固定行，带锁图标 |
| **PriceBlock** | mono 价格 + 计费方式 +「验收后付款」说明；原型中加「示例价格」 |
| **EvidenceRow** | 三格 mono 数字 + 「来自 DSH 记录」；样本不足时整行替换 |
| **Timeline** | 任务时间线：Agent 事件（运行时图标）与维护者事件（头像）区分；复核为一枚「已复核」印章 |
| **RuntimePicker** | 招募面板内单选卡，列出已连接 Agent 的官方图标与最近活动；不支持的置灰写原因 |
| **TabBar** | 4 项；选中项 ink 文字 + 上方 2px 挂绳色短线 |
| **Canvas WorkerNode** | 迷你工牌 240 宽：挂孔、色带 24px、名称、维护者、运行时图标、版本；连线端口 8px |

## 不要做

- 渐变、发光、模糊玻璃、插画、emoji。
- 把 Grok / Muse 图标重新着色或放进自定义底板。
- 装饰性数字；非 DSH 统计的实心大数字。
- 生成「真人」照片冒充维护者。
