# AI Worker 商业模式研究

> 检索时间：2026-10-30。标注「待核实」的条目来自公开检索摘要，尚未取得一手条款。所有价格与分成比例在接入支付合作方前都只是提案。

## 1. 市场参照

| 平台 | 供给方是谁 | 用户拿到什么 | 创作者怎么赚钱 | 对我们的启示 |
|---|---|---|---|---|
| **Grok Bot 模板**（xAI） | 任意用户 | 一份「配方」：身份、指令、skills、routines、memories、plugins；添加后是**独立副本**，不含创作者的登录、历史、密钥、自定义脚本；可公开或仅团队链接分享 | 公开资料未见付费机制（待核实） | 体验标杆：一键添加、先审查权限再启用。缺口：复制即断联，创作者无法持续维护，也无法收费 |
| **Meta Muse**（2026-09-08 发布） | Meta | 个人 Agent：每个用户一台独立虚拟机（文件系统、终端、浏览器），关键动作需要人工确认；iOS / Android / Mac / Web / WhatsApp | 基础免费，高级自动化需要 Meta AI 订阅 | 买家自己的算力和授权已经付过费 → 我们可以「装到你的 Agent 上」而不承担推理成本 |
| **Poe**（Quora） | Bot 创作者 | 在 Poe 内对话 | 创作者自定义按消息计费；另有订阅引荐分成（检索摘要：首月 100% / 年付首期 50%，待核实） | 按次计费可行，但计价单位是「消息」，与结果无关 |
| **GPT Store**（OpenAI） | GPTs 创作者 | 在 ChatGPT 内使用 | 未见确认的公开分成；创作者多引流到外部付费墙 | 纯模板商店的变现很弱 |
| **Coze** | Bot 开发者 | 平台内 Bot | 点数按次 / 订阅；分成比例未公开（待核实） | 平台内结算是标配 |
| **Fiverr Go** | 自由职业者 | 买家购买该自由职业者「个人 AI 模型」生成的作品 | 自由职业者付工具费：Creation Model $25/月、AI Assistant $29/月（或 Seller Plus Premium 内含） | 最接近我们：**真人 + 训练过的 AI + 真人对结果负责**；买家为结果付费 |
| **Fiverr / Upwork** 传统外包 | 自由职业者 | 人工交付 | 平台按成交抽佣（公开资料约 10%–20%，含买家服务费，待核实） | 托管付款 + 验收放款是成熟机制 |

来源：Poe Creator Platform《Creator Monetization》；muse.ai 官网与发布报道；Grok Bot 模板公开说明；Fiverr Go 公开定价。

## 2. 结论：钱在哪里

1. **模板本身几乎不值钱**：复制零成本，GPT Store 与 Grok 模板都证明了「好用」不等于「能收费」。
2. **人们愿意为「持续负责」付费**：Fiverr / Upwork 的抽佣建立在「有人对结果负责 + 验收后放款」上。
3. **算力已经被个人 Agent 订阅覆盖**：Muse、Grok 的用户已经在为自己的 Agent 付费。我们不必再卖推理，只卖「把这件事做对」的工作包与维护。

**定位**：AI Worker 卖的是「可复制的说明书 + 不可复制的维护和担责」。价值单位是**一次被验收的交付**，而不是消息或 token。

## 3. 参与方与价值流

```
           订阅费 / 按验收付款（托管）
  业主 ─────────────────────────────▶ DSH 托管账户 ──(验收后 85%)──▶ 维护者
   │                                    │
   │ 自己的 Grok Bot / Muse 订阅          └─(15% 平台费)──▶ DSH
   ▼
 个人 Agent ◀── 工作包（指令 + skills + 工具权限 + 版本）── 维护者持续更新
   │
   └─ 交付 ──▶ 〔维护者复核〕──▶ 业主验收 ──▶ 触发放款
```

## 4. 两种运行模式

| | A. 装到我的 Agent（默认） | B. 维护者托管 |
|---|---|---|
| 谁执行 | 业主绑定的 Grok Bot / Muse / 其他 | 维护者自己的 Agent（即现有 `agentService` 模型） |
| 推理成本 | 业主已有订阅 | 维护者承担 → 价格更高 |
| 工作包可见性 | 指令会进入业主的 Agent（接受被看到） | 不外发，只回传交付 |
| 适合 | 标准化流程：上架、询盘整理、选品报告 | 需要维护者私有资料、私有工具的任务 |
| DSH 角色 | 签发任务级凭证、推送版本、记录交付 | 同左 + 维护者 Agent 的租约与心跳 |

## 5. 收费结构（提案）

| 层 | 内容 | 示例价格 |
|---|---|---|
| 免费 | 公开模板、无真人承诺；等同 Grok 模板体验，用于获客 | ¥0 |
| **订阅** | 每 Worker 每项目按月；含版本更新、每月 N 次维护者复核、维护者自述响应时间 | ¥99–499/月 |
| **按验收** | 单任务定价；审批时冻结到托管账户，验收后放款，退回则重做或退款 | ¥20–300/次 |
| 加项 | 加急、额外人工复核 | 按次 |

平台费：维护者收入的 15%（低于传统外包平台常见区间，用于吸引供给）；支付通道费另计。

## 6. 单位经济示例（假设）

一个「跨境商品上架」Worker，订阅 ¥299/月，40 个订阅：

$$\text{GMV} = 299 \times 40 = 11{,}960$$

$$\text{平台收入} = 11{,}960 \times 15\% = 1{,}794 \qquad \text{维护者收入} = 10{,}166$$

每个订阅每月 4 次复核、每次 10 分钟 → 维护者每月投入约 26.7 小时，折合约 ¥381/小时。模式 A 下平台无推理成本，毛利主要被支付通道与审核运营消耗。

## 7. 冷启动与飞轮

1. **自营种子供给**：用 DSH 已有能力做第一批 Worker（选品、商品上架、买家杂志、询盘找回），由内部团队担任维护者，先跑出真实验收记录。
2. **定向邀请**：邀请外贸 / 电商领域的自由职业者，把他们已经在做的 SOP 打包成 Worker。
3. **发布门槛**：至少 1 次真实试运行并验收才能上架。
4. **飞轮**：真实验收数据 → 更可信的排序 → 更多雇用 → 维护者收入 → 更多维护投入。

## 8. 风险

| 风险 | 应对 |
|---|---|
| 指令被复制 | 价值放在持续更新、复核与担责；需要保密的走模式 B |
| 依赖第三方 Agent 条款 | Grok Bot / Muse 是否允许第三方工作包安装与商业分发：**待核实**；保留「其他 Personal Agent」与模式 B 作为退路 |
| 质量与纠纷 | 验收前不放款；退回必须写原因；证据（交付物 + 任务记录）用于仲裁 |
| 责任边界 | 维护者协议明确服务范围；Worker 不对外发消息、不支付 |
| 国内收款合规 | 需要具备分账能力的持牌支付合作方，DSH 不自建资金池 |
| 刷数据 | 统计只来自不同业主的验收；同一业主重复验收降权 |

## 9. 北极星与指标

- 北极星：**每周被验收的交付数**。
- 漏斗：浏览 → 雇用 → 首次验收（7 天内）→ 第 2 个月续订。
- 供给健康：维护者复核中位时长、退回率、每维护者活跃 Worker 数。
- 收入：GMV、平台费、托管中金额、退款率。

## 10. 与当前 DSH 的距离

- 已有：Worker 身份与专用凭证、任务审批与范围限制、交付与验收、Grok / Muse 适配器。
- 缺：模板 / 版本 / 绑定记录、支付与托管、维护者结算、订阅计量。Grok Bot 任务目前只支持零预算。
