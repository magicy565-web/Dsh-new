# 真实流程研究：采购对接与运营

> 目的：用采购方和出口商实际在跑的流程，校准 Sourcing Agent 的阶段与闸门。
> 结论先说：现在的六道门停在「找到买家、发出开发信」，而真实工作从**供应商资料包、RFQ、样品确认、验厂、合同、首单、验货、单证、收款、绩效**才开始。

## 一、采购方是怎么引入一家供应商的

中国企业（中大型）的供应商入库（vendor onboarding）标准路径，7 个环节：

1. **业务申请与立项**：说明品类、场景、预计年采购额。
2. **资格预审**：基础资质有效性验证，剔除明显不合格对象。
3. **资质与合规校验**：工商、税务、银行四要素、涉诉/舆情、黑名单、关联方。
4. **尽职调查与评分**：财务稳健、交付能力、质量与安全体系、信息安全，量化评分并分级。
5. **协议签署**：框架合同、保密协议、廉洁条款、数据处理协议。
6. **主数据建档**：ERP/SRM 建供应商编码、银行账户、发票信息、结算条件。
7. **首单试供与复核**：小额/低风险订单试供，监控交付、质量与对账。

采购方自己用的验收指标：一次通过率 ≥70%、入库平均 TAT ≤10 个工作日、试供阶段无重大质量/合规异常、重复建档率 ≈0。
来源：[供应商入库流程办法和标准（2026实操版）](https://www.seeyon.com/article/rZ69CBOE.html)

### 资料清单（采购方实际会收的）

| 类别 | 具体文件 |
|---|---|
| 主体 | 营业执照/统一社会信用代码证（国家平台可查、状态正常） |
| 授权 | 法定代表人证明、授权委托书（授权链清晰、有效期覆盖签约周期） |
| 财务 | 开户银行证明、银行四要素（户名/账号/银行/证件一致）、一般纳税人资格与开票信息 |
| 体系 | ISO9001 / 14001 / 45001 / 27001（按品类要求） |
| 行业许可 | 生产许可、特种设备、食品/化妆品/医疗器械等按监管要求 |
| 合规承诺 | 反商业贿赂、数据保护、出口管制条款确认 |
| 能力 | 组织架构图、品质架构图、工艺流程图、品质控制流程图 |

## 二、采购方是怎么开发一家新供应商的

制造业采购的「新供应商开发」8 步，和上面的入库是前后衔接的两段：

1. **需求识别与供应商搜寻**（成本、质量、交期、新产品）。
2. **初步评估**：发《供应商调查表》，同时收营业执照、税务登记、开户资料、认证证书（ISO、产品认证、RoHS）、组织架构、品质架构、工艺流程图、品质控制流程图。
3. **详细评估**：会谈确认产品、价格、质量、交货、配合度。
4. **现场考察**：生产环境、设备、管理水平；依据《供应商现场评估报告》评级；贸易商/代理商可申请免实地审核。
5. **询价比价**：至少两家报价，要求正式报价单；必要时提供材料成本明细。
6. **样品测试**：使用部门确认，签批《样品确认单》。
7. **小批试产**：试产 1-3 次，品质部检验合格。
8. **供应商导入**：填《供应商导入申请表》，进系统合格供应商名录。

来源：[企业开发新供应商流程范例](http://qms.foodmate.net/news/show.php?itemid=172268)

**关键点**：采购方在「报价」之前就要资料包和现场评估；样品确认是**书面签批**，不是口头说好；小批试产合格才算导入。这三件事在现在的 v1 里都没有。

## 三、出口商侧的订单执行（拿单之后）

出口企业实际在跑的 9 步：

1. **找客户 + 报价**：报价单写清贸易术语（FOB/CNF/CIF）、付款方式（T/T、L/C）、有效期。
2. **询盘 → 报盘**：规格、数量、单价、总价、交货期、包装。
3. **合同 + PI**：客户 PO 后签外销合同、开形式发票；「钱或证到手再下一步」。
4. **收定金/审证 → 生产**：生产单的规格、包装、标签必须与客户确认版本一致。
5. **订舱 + 报关**：报关资料（发票、箱单、合同）金额、件数、HS 编码必须一致。
6. **开船 → 结汇单证**：商业发票 CI、装箱单 PL、提单 B/L、产地证 CO；L/C 下单据必须严格一致。
7. **单证核对 + 催尾款**：款不到不放单（正本提单或电放）。
8. **收尾款 + 结汇**：「谁出口谁收汇」，避免第三方代收影响退税。
9. **工厂开票 + 出口退税**：报关单、增值税专用发票、收汇水单、运输单据；次月申报。

来源：[外贸出口全流程：从报价到退税的9个步骤](https://m.sohu.com/a/1013965845_122351577/)

## 四、质量：验货与缺陷分级

- 抽样依据 **GB/T 2828.1（等同 ISO 2859-1）**，按批量、检验水平（一般 I/II/III）、AQL 值确定样本量与判定数。
- 缺陷分三级：**致命（CR）/ 严重（MA）/ 轻微（MI）**；实践中常把轻微再拆，形成 A/B/C/D 四级。
- 典型 AQL：致命 0、严重 1.5-2.5、轻微 4.0（按品类与客户要求调整）。
- 验货时点：**产中（DUPRO）** 与 **出货前（PSI）**；报告要记录抽样数、缺陷数、判定、照片。
- 汽车/工业件另有 **PPAP**（生产件批准程序，含 FAI 首件检验、控制计划、MSA、PSW），消费品一般不强制，但大客户会要求首件确认。

来源：[物料缺陷的分级判别方法](https://m.anytesting.com/news/1923784.html)、[PPAP 说明](https://grayhill.com/blog/how-grayhill-ensures-supplier-quality-through-ppap-pfmea-and-control-plans/)

## 五、贸易术语与收款

Incoterms 2020 共 11 种，按运输方式分两类；关键不是价格，而是**风险转移点、出口/进口清关责任、保险义务**：

| 术语 | 风险转移 | 出口清关 | 进口清关 | 保险 |
|---|---|---|---|---|
| EXW | 工厂交货 | 买方 | 买方 | 无 |
| FCA | 交承运人 | 卖方 | 买方 | 无 |
| FOB（海运） | 装船 | 卖方 | 买方 | 买方 |
| CFR（海运） | 装船 | 卖方 | 买方 | 买方 |
| CIF（海运） | 装船 | 卖方 | 买方 | 卖方（最低险） |
| CIP | 交承运人 | 卖方 | 买方 | 卖方（最高险） |
| DAP | 目的地待卸 | 卖方 | 买方 | 卖方自愿 |
| DPU | 目的地卸货 | 卖方 | 买方 | 卖方自愿 |
| DDP | 目的地完税 | 卖方 | 卖方 | 卖方自愿 |

来源：[贸易术语详解（中国贸促会）](https://www.eccpit.com/trendings/Y21zcG86MTI3MTM)、[ICC Incoterms 2020](https://iccwbo.org/business-solutions/incoterms-rules/incoterms-2020/)

收款方式：T/T 定金 + 见提单副本付尾款最常见；L/C 按 UCP 600 审单，**单证不符点直接扣款/拒付**；新客户大额订单才考虑 L/C，小额全款或信保。合同条款要写：质量异议期、索赔与罚款、不可抗力、知识产权、独家与区域限制。

## 六、DTC 运营实际在跑什么

独立站从 0 到 1 的三段节奏：

- **0-30 天 MVP**：选品（需求上升、客单 >50 美元更易覆盖流量）、建站（首页/产品页/购物车/结算/联系页 + GA4）、小额投放测试。
- **30-60 天 优化**：信任徽章、弃购挽回 3 个节点（1h/24h/72h）、关停 ROAS<2 的广告组、扩相似受众。
- **60-90 天 盈利**：会员体系提 LTV、垂直 KOL 联盟。

来源：[独立站从0到1实战指南](https://www.upkuajing.com/knowledge/zixun/22244)

履约是 6 个环节：收货 → 仓储与库存 → 订单处理 → 拣货打包 → 发货 → 退货逆向。3PL 上线是 5 步：系统对接 → 库存转入 → SKU/条码数据 → 测试订单 → 正式切换与监控。合同要看：最低消费、库内损耗责任、SLA（准确率/准时率）、费率调整、退出与库存取回。
来源：[Ecommerce Fulfillment Guide](https://www.fulfill.com/ecommerce-fulfillment)

DTC 的硬风险：3DS 与拒付、别用个人 PayPal 收款、欧盟 IOSS、发货时效 <72h、GDPR 隐私条款、产品图版权。

## 七、和现在 v1 的差距

| 真实环节 | v1 有没有 | 结果 |
|---|---|---|
| 目标客户画像与品类策略 | 弱（只有市场选择） | 名单容易泛 |
| 供应商资料包（证书/体系/产能/QC 流程） | 无 | 买家一问资质就卡住 |
| 供应商调查表 / RFI 回答 | 无 | 无法进入买家短名单 |
| 现场评估 / 验厂 / BSCI/SMETA | 无 | 大客户直接淘汰 |
| RFQ 正式报价（成本明细、有效期、条款） | 只有「报价口径」 | 报价不可比、易被压价 |
| 样品确认单与打样跟踪 | 无 | 样品阶段失控 |
| 合同条款（质量、索赔、罚则、IP） | 只有 handoff 提示 | 风险裸露 |
| 首单/试产/PPAP/FAI | 无 | 量产爬坡无控制 |
| 验货（AQL、CR/MA/MI、PSI） | 无 | 出货质量不可控 |
| 出口单证与收款节点（B/L 放单） | 只有清单 | 钱货脱节 |
| 供应商绩效（OTIF、PPM、回复率） | 无 | 无法复购与提价 |
| DTC 履约与 3PL 上线 | 无 | 上线即爆仓/超时 |

一句话：v1 把「商机」当成终点，真实流程把「商机」当成起点。

## 八、专家检查清单（可直接进闸门）

### B2B 供应商侧

1. 目标客户画像：细分、规模、采购频次、现有供应来源、决策人。
2. 资料包：营业执照、开户信息、一般纳税人、ISO/产品认证、组织与品质架构、工艺与 QC 流程图。
3. 能力证明：产能、MOQ、交期、打样周期、关键设备清单、可公开客户案例。
4. 合规：目的国认证、REACH/RoHS、包装法/EPR、验厂报告（BSCI/SMETA/客户审核）。
5. RFQ 回复：规格符合性、阶梯价、贸易术语、有效期、付款方式、包装与装箱量。
6. 样品：打样单、寄样记录、确认单（书面）、修改闭环。
7. 合同：质量异议期、索赔、罚则、IP、独家与区域、不可抗力。
8. 首单：PO 确认、排产、产中验货、出货前验货（AQL）、整改闭环。
9. 单证：CI、PL、B/L、CO、保险、MSDS/熏蒸（按需），单单一致、单货一致。
10. 收款：定金到账、尾款条件、放单控制、收汇与退税匹配。
11. 绩效：OTIF、批次合格率/PPM、回复时效、报价成交率、复购。

### DTC 品牌侧

1. 需求验证：搜索趋势、竞品评价、价格带、毛利空间。
2. 供应链：3 家报价、打样、QC 清单、MOQ 与补货周期。
3. 经济模型：到岸成本、平台/支付费、履约费、退货率、CAC、盈亏平衡 ROAS。
4. 合规：认证、标签、责任主体、税务（VAT/IOSS/销售税）、隐私政策。
5. 店铺：页面结构、支付、物流费率、政策页、像素与事件。
6. 上线：素材 3 角度 × 3 钩子、预算阶梯、止损线。
7. 履约：3PL 上线 5 步、SLA、退货地址、库存周转与补货点。
8. 复购：欢迎/弃购/购后/唤醒流程、评价、会员。
9. 复盘：CVR、AOV、CAC、ROAS、退款率、库存周转、贡献毛利。
