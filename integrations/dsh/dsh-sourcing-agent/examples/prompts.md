# 第一句话怎么问

选中 **Sourcing Agent** 后，直接给业务事实，不要寒暄。以下可直接改括号内容使用。

它会先建立项目记录（`sourcing_project`），把缺的事实列成开工清单，然后按所选路线逐道过闸：**DTC（当前主线）** 市场 → 产品与供应链 → 单位经济 → 品牌与店铺 → 上线与投放 → 履约与客服 → 增长与复购 → 复盘；**B2B（beta）** 立项 → 市场 → 供给 → 单位经济 → 资产 → 交接。每过一个闸门，产出物写进 `sourcing/<slug>/`。

## 模式2 品牌出海（主线）

- 「我想做一个（宠物/家居/户外）品牌，预算（金额），完全不懂运营，帮我从选品做到上线。」
- 「我对（品类）有兴趣，但没有具体产品想法。给我 3 个可以做的方向，算清成本，选一个开始。」
- 「我已经有（产品），想做自己的独立站品牌，目标市场（美国），预算是（金额），帮我把店、素材和投放都准备好。」

## 模式1 供货出海（beta）

- 「我在（城市）做（产品），月产能（数量），现有认证（CE/ISO/…），想做（德国/美国/中东）市场，帮我找买家和渠道。」
- 「（产品）的成本是（金额），现在只做国内。我想做出口，但不知道先打哪个国家，帮我选市场并给出报价口径。」
- 「我有一个（产品）的货源，但没有外贸团队。给我一份 30 天的开发计划和可以直接发的开发信。」

## 继续推进

- 「按你的建议继续，先把市场报告写完。」
- 「这一阶段先渲染产出物，再推进闸门。」
- 「把供应商报价导出成 CSV，按 MOQ 排序。」
- 「生成 handoff 清单，我明天照着做。」
