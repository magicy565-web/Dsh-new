# 模式1：供货出海（B2B，beta）

> 当前产品主线是 DTC 品牌线（八道门）。B2B 线暂时冻结在 v1 六道门：立项 → 市场 → 供给 → 单位经济 → 资产 → 交接。本技能保留给已有 B2B 项目的领域打法；等 B2B v2（资料包、RFI、RFQ、样品、验厂、合同、首单、交付）落地后再升级。

目标不是一份报告，而是让海外买家开始回复、打样、报价、下单。30 天成功标准：20-50 个合格目标、30 次有效触达、8-12 个回复、2-3 个打样或报价。

本技能只负责模式1 的领域打法；项目状态、证据、名单、成本与闸门由 `sourcing_*` 工具维护：

- 市场候选与推荐 → `sourcing_markets`
- 渠道与买家 → `sourcing_leads`（一行一条，带 sourceUrl；域名自动去重）
- 报价成本 → `sourcing_economics`（b2b 口径）
- 开发信与跟进 → `sourcing_render` 的 `outreach` + `markdown.outreach` 叙事
- 买家表 → `sourcing_render` 的 `buyers`（CSV 由记录生成，不要手拼）

## 第1步 供给事实表

写进项目事实（`sourcing_facts`），不是自由文本：

- 产品名、型号、核心规格、材料、单件重量与包装尺寸（决定运费与关税）
- 月产能、MOQ、生产周期、打样时间与费用
- 价格口径：EXW 出厂价 / FOB 港口 / CIF / DDP，币种，有效期；阶梯价
- 认证与检测：证书编号、签发机构、有效期、覆盖型号；缺哪一项
- 定制能力：OEM / ODM、LOGO、包装、颜色、电压与插头、说明书语言
- 可公开的客户或案例（不能公开的不要写）

用户没给的数字写「待确认」，不要用行业平均值冒充自家数据。企业资料库里有产品与证书时先读 `workspace_library_*`，以库里的版本为准。

## 第2步 选市场

候选 3-6 个，用加权打分（1-5 分，写依据）：

| 维度 | 权重 | 看什么 |
|---|---|---|
| 需求与进口规模 | 25% | 该国该 HS 编码的进口额与增速（UN Comtrade、OEC、海关统计） |
| 竞争强度 | 15% | 本地品牌、中国同行、平台同款数量与价格 |
| 合规门槛 | 20% | 认证、注册、标签、责任主体要求与费用 |
| 物流成本 | 15% | 海运 / 空运单价、时效、是否适合小包 |
| 付款与汇率风险 | 10% | 主流付款方式、外汇管制、信用环境 |
| 渠道可达性 | 15% | 能否找到可联系的买家与代理，语言门槛 |

输出 `01-market.md`：打分表 + 推荐 1 个主市场 1 个备选，写清「为什么是它、为什么不是别的」。HS 编码必须去海关或目的地关税数据库核对，不要凭记忆。

## 第3步 买家地图

先定细分，再定渠道。每个细分要写清决策人、采购周期、典型 MOQ、最在意什么：

| 细分 | 决策人 | 最在意 |
|---|---|---|
| 进口商 / 分销商 | 采购经理 | 独家区域、价格、稳定供货 |
| 批发商 / 现货商 | 老板 | 现货、小批量、快速补货 |
| 连锁零售 | 品类经理 | 合规、包装、交期、验厂 |
| 自有品牌商（private label） | 采购 / 产品经理 | OEM 能力、打样速度、MOQ |
| 电商品牌与大卖 | 创始人 / 供应链 | 小单快反、一件代发、包装 |
| 工程项目与招标 | 项目经理 | 资质、交期、技术文件 |

渠道按可达性排序，每个渠道给一句可直接粘贴的检索式：

- 展会参展商名录（按品类选：Ambiente、Canton Fair、Nuremberg Toy Fair、CES、National Hardware Show 等）→ `"<展会名>" exhibitor list <品类>`
- B2B 目录：Kompass、Europages、ThomasNet（北美）、wlw（德语区）→ `site:kompass.com <品类> <国家>`
- 进口数据：ImportYeti、ImportGenius、Panjiva → 按 HS 编码或品名查实际进口商
- LinkedIn：`"purchasing manager" "<品类>" <国家>`、`"category manager" "<品类>" <国家>`
- 平台品牌反查：亚马逊 / 独立站同款品牌 → 找到公司主体与采购入口
- 被动询盘：Alibaba RFQ、中国制造网、环球资源
- 本地商会、行业协会会员名录、黄页

## 第4步 名单与核验分级

`02-buyers.csv` 列：`公司, 国家, 细分, 网站, 联系人, 职位, 邮箱, 电话, 来源链接, 匹配点, 进口信号, 分级, 核验级别, 下一步, 日期`。

- A 级：明确进口同类产品，且有采购职能与可联系入口。
- B 级：主营相关，需进一步确认是否采购。
- C 级：只有目录信息，未打开官网核实。
- 核验级别：`官网已核实` / `第三方数据` / `仅目录信息`。后两者不能写成「已联系」或「已确认」。

宁少勿假：20 条真实线索胜过 200 条编造名字。每条都要有来源链接。

## 第5步 报价与条款

成本阶梯，逐项列明：

```
材料 + 人工 + 包装        = 出厂成本（EXW）
+ 国内运输、报关、订舱     = FOB 成本
+ 海运 / 空运 + 保险       = CIF 成本
+ 目的港费用、关税、清关、末端派送 = DDP 成本
```

报价单要素：型号、规格、MOQ、阶梯单价、贸易术语与港口、币种、有效期、付款方式、交期、包装方式、随货文件。报价单用 PDF 或 xlsx 发出。

- 付款：新客户 T/T 30% 定金 + 70% 见提单副本；大单可谈 L/C；不要无条件赊账。
- 样品：收样品费 + 运费到付，正式下单可退；样品单是最有效的成交工具。
- 筹码：阶梯价、交期、包装定制、混装、区域独家（谨慎给，绑定年度采购量）。
- 毛利核算：`(FOB 单价 - FOB 成本) / FOB 单价`，低于 15% 要提示风险。

## 第6步 开发信与跟进

原则：一屏读完、无附件、无群发痕迹、只问一个容易回答的问题、第一句证明你做过功课。

结构：他们的现状（1 句）→ 你能解决的具体问题（1-2 句，带数字）→ 证据（认证、客户类型、交期）→ 低门槛下一步（寄样 / 15 分钟通话 / 报价）。

主题行 ≤ 6 个词，具体，不用 `Cooperation`、`Best price`、`Supplier from China`。

跟进节奏：D3 补价值（规格表或案例）、D7 换角度（阶梯价或交期）、D14 收尾（明确关闭，留门）。每条跟进只加一个新信息。

渠道变体：LinkedIn 连接请求 ≤ 300 字符；WhatsApp 首条只发文字，用户回复后再发资料。

红线：不 BCC 群发、不首封发 10MB 目录、不承诺做不到的交期、不虚报认证与产能。

## 第7步 询盘处理

24 小时内回复。结构：确认需求（型号、数量、目的地）→ 报价（含贸易术语与有效期）→ 交期与 MOQ → 认证与文件 → 下一步（寄样 / 视频验厂）。

被压价时先问用途、数量与目标市场，再给三个方案（降价换配置 / 加量换价 / 缩短账期），不要一次让到底。

## 第8步 合规与单证

按目的地核对（以官方为准，只提示风险）：

- 欧盟：CE（按适用指令）、REACH、RoHS、WEEE、包装 EPR 注册、标签与欧代
- 英国：UKCA、UK REACH
- 美国：FDA（食品接触 / 化妆品 / 医疗器械）、FCC（无线与电子）、CPSC（儿童与消费品）、Prop 65、UL / ETL（渠道常要求）
- 日本：PSE、食品卫生法；中东：SASO；俄罗斯：EAC

单证：商业发票、装箱单、提单、原产地证（CO / FTA 优惠原产地）、MSDS（危险品）、木包装熏蒸证明。

认证是「主体 + 产品 + 工厂」的组合，不能借用别家证书；费用与周期写进预算和时间表。

## 第9步 30/60/90 与 KPI

- 30 天：名单 50、首触 30、回复 8-12、样品 2-3
- 60 天：报价 5-8、试单 1-2
- 90 天：稳定订单 1-2、翻单或复购 1

KPI：回复率、样品转化率、报价成交率、平均订单额、回款周期、获客成本。每周用 `sourcing_leads update` 更新状态列。
