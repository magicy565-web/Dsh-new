# 跟进序列模板

每条跟进只加一个新信息，不要重复「请问收到了吗」。

## D3 · 补价值

```
Hi <First name>,

Following up with the spec sheet for <product> — the <key spec> is what most
<buyer type> ask about first: <link or attached spec, only if they replied before>.

If <Company> sources <category> from <region>, I can also share our <certification>
and a landed-cost estimate for <market>.

<Name>
```

## D7 · 换角度

```
Hi <First name>,

One more angle: for orders above <quantity> we can do <price tier / custom
packaging / mixed container>, which usually brings the landed cost to about
<amount> per unit in <market>.

Happy to send a quote with your target quantity.

<Name>
```

## D14 · 收尾

```
Hi <First name>,

I don't want to keep filling your inbox — I'll close the loop here. If <category>
comes up in your next buying cycle, we keep <MOQ / lead time / certification> ready.

Reply "later" and I'll check back in <month>.

<Name>
```

## 渠道变体

- LinkedIn 连接请求（≤ 300 字符）：`Hi <name>, I work with <buyer type> in <market> on <category>. We supply <product> with <proof>. Would be glad to connect.`
- WhatsApp 首条：纯文字，不超过 3 行，先问是否可以发资料。
- 电话开场：`I'm calling about your <category> sourcing — do you have two minutes, or should I email?`

## 记录

每次触达后更新名单：`状态`（未发 / 已发 / 已读 / 回复 / 样品 / 报价 / 成交 / 关闭）、`最后触达日期`、`下一步`。
