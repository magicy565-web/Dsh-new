# 按任务交付

根据用户要的结果选择文件，不要求成套报告、固定目录、仪表盘或全套附件。
简单回复可直接给文字；需要文件时使用当前工作区的原生文件／shell 工具生成，验证后用 present 交付（若该工具可用）。

## 内容与格式

研究报告先给结论、依据、假设与缺口，再给必要细节。涉及来源时保留网址与访问日期。
买家表记录实际找到的主体与核验状态。报价列清币种、单位、贸易术语及尚未确认条件。

CSV 保持一致列名与类型，面向 Excel 中文用户可使用 UTF-8 BOM。金额、币种和比率分列；未知值不当作零。
只有需求需要时才生成 xlsx、docx 或 PDF；使用已安装的适当工具，并检查文件可打开。缺工具就交付可用格式或说明限制，不声称已经转换。

模板中的占位符和示例数字必须替换或明确标为待确认。产品性能、认证和客户说法保留对应依据。

## 交接与核对

账号、付款、发布或外部联系需要实际授权；交接只列这次确实阻塞的动作、所需资料与负责人。
写入前检查已有文件，保留用户工作，不为了统一目录而覆盖已有成品。
交付前核对数字口径、来源、占位符及文件路径。最终回复简述结果并链接本次成品，不把计划写成已经执行。
