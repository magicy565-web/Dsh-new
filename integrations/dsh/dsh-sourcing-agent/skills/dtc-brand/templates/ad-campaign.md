# 投放计划模板

## 素材角度（先定 3 个）

| 角度 | 目标人群 | 前 3 秒钩子 | 证明方式 | 时长 |
|---|---|---|---|---|
| 痛点 | | | 使用前后对比 | 15-30s |
| 效果对比 | | | 与旧方案对比 | 15-30s |
| 场景故事 | | | 真实使用场景 | 30-45s |

每个角度写 3 条不同钩子的脚本，同一素材只改开头。

## Meta 结构

- Campaign：`<brand> — prospecting — <market>`
- Ad set A：兴趣（3-5 个相关兴趣）
- Ad set B：类似受众（1-3% 种子：购买或加购）
- Ad set C：广泛（仅国家 + 年龄 + 性别）
- 每个 ad set 3 条素材，同一落地页
- 预算：每日 $30-50 起，3 天为一个判断周期
- 优化目标：先 `Purchase`，事件不足时用 `Add to cart`

## TikTok

- 自然流：每周 5-7 条，内容比例 3 教育 : 2 场景 : 1 产品
- Spark Ads：只放量已跑出 CTR 与完播的素材
- 达人：先寄样 10-20 个中小达人，按 CPA 结算优先

## Google

- 品牌词 Search（防守）
- Shopping / PMax（承接比价需求）
- 否定词表：cheap、free、diy、repair

## 判断与止损

| 指标 | 健康值 | 处理 |
|---|---|---|
| CTR | > 1.5% | 低于 0.8% 换钩子 |
| CPC | < 售价的 2% | 高于 3% 换受众 |
| 加购成本 | < 售价的 25% | 超标先修落地页 |
| ROAS | > 盈亏平衡 ROAS | 连续 3 天低 30% 关 ad set |

花费超过 2 倍客单价仍无加购：立即停该素材。
