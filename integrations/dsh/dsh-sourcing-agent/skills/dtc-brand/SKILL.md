# 自有品牌方法

围绕当前问题选择以下分析维度，不设固定路线、数量门槛或完成顺序。

## 定位与供应链

用目标人群、场景、问题、替代方案与价格带解释定位。比较供应商时记录报价口径、MOQ、样品费、响应、交期、包装和质量问题；没有实际样品就标为未验证。
检验项按产品风险选择：尺寸、外观、功能、材料、包装与标签等，不能把示例检查表当作已完成检验。

## 单位经济

采用一致币种、税费和订单／件口径，列明采购、头程、关税、支付、平台、履约、退货与广告成本的来源或假设。
- 广告前贡献 = 净销售收入 − 非广告可变成本。
- 广告前贡献率 = 广告前贡献 / 净销售收入。
- 广告后贡献 = 广告前贡献 − 获客成本。
- 在营收与广告归因口径一致、贡献率为正时，盈亏平衡 ROAS = 1 / 广告前贡献率。
- 目标 ROAS = 1 /（广告前贡献率 − 目标利润率），仅在分母为正时有意义。

按需要做价格、获客成本、退货率敏感性分析。没有统一适用于所有品类的毛利、客单价或投放阈值。
使用 templates/unit-economics.csv 时替换示例输入并保留假设列，不把空白单元格当零。

## 店铺、营销与履约

按实际请求处理产品页、支付与运费、退换政策、事件追踪、素材角度、客服或履约方案。
支付成功、测试订单、像素验证、样品收到、库存入仓等只有实际证据才可写为完成。
广告预算、素材数、止损点和客服时效应来自用户约束和实际经济模型；计划不是投放或发布授权。

## 复盘

结合实际数据看转化率、客单价、CAC、ROAS、退货和周转；来源不足时给出需要的数据，不编造经营结果。
补货点可按日均需求 × 补货交期 + 安全库存估算，说明需求波动、交期假设与服务水平。

按任务选择 templates/brand-brief.md、templates/product-page.md、templates/ad-campaign.md 或 templates/launch-calendar.md。
