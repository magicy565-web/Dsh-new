# 按本期要求组装微刊

每次创建先确定读者、目的及本期模块清单。用户已指定模块时直接使用；只描述目的时，先提出精简组合，并按已有授权继续。缺少会实质改变结果的信息才提问。不默认加载十个模块，不要求按目录顺序完成其他业务工作。

## 十个可选模块

| ID | 模块 | 需要的信息 |
| --- | --- | --- |
| product | 产品展示 | 产品介绍、差异、可选图片和原页 |
| buyer-fit | 为什么推荐给你 | 买手实际客群、渠道、价格带与匹配理由 |
| opportunity | 产品机会点 | 观察信号、编辑判断、未验证假设 |
| launch | 新品首发 | 上市状态、时间依据、首批安排 |
| sales-history | 同类历史销售 | 同类对象、销售金额、时间、市场、渠道、口径与来源 |
| margin | 销售利润测算 | 同币种单件售价、成本、渠道费率与假设 |
| comparison | 同类产品对比 | 比较维度、逐项信息、可比性限制 |
| procurement | 采购条件 | 采购价、MOQ、交期等已知条款，未知项明确待确认 |
| sample | 样品申请 | 费用、条件及真实申请地址 |
| exclusive | 独家供应名额 | 确认状态、区域、渠道、期限、条件及供应方入口 |

一个模块可以放在整期层面，也可通过 product 标签属于某个产品。同一期不同产品可以使用不同组合；同一类型可重复出现，但块 id 唯一。blocks 数组的顺序就是版面顺序，未选模块不会生成。

## 获取和组织资料

只为选中模块获取必要资料，复用现有原生文件、网页或已接入的数据工具。不得声称已接入 FastMoss、Kalodata、AutoDS 或供应商库存，除非实际工具可用并成功读取。

事实绑定实际来源；已读取、用户提供、估算和排版示意分开标注。不得编造历史销售、买手偏好、未首发状态或供应名额。销售数据注明统计范围、GMV/净销售等口径和来源索引，估算不能升级为实际收入；同类历史不等于本品未来表现。

利润使用同币种、同税口径的单件输入。未知成本不能填 0；要么取得资料，要么把有依据的假设写明，要么省略该模块并说明原因。计算结果是所列成本下的贡献利润，不是净利润或回报保证。

独家模块只有真实供应方材料才能写 confirmed。slots 只是带 asOf 的名额快照；静态文件不能锁库存、收定金或确认合同。CTA 进入供应方真实渠道，不能把点击、收藏或本地状态当作已锁定。无实际入口则展示条件，不编造链接。sample 同理，不把费用未知写成免费。

已明确选中的模块如果资料不足，指出具体缺口，按用户要求补充、注明待确认或省略；不得静默填造内容。

## 生成文件

数据结构和字段说明见 `MODULES.md`。`templates/layout-preview.json` 是含十种模块的**排版示意**，其中金额和权益均为测试内容，不能作为真实商业稿。

使用原生文件工具创建本期 JSON，只写入所需 blocks；语言支持 zh / en，编辑正文使用目标读者语言。以本 skill 的 resourceBase 解析脚本路径：

```sh
node <skill-directory>/scripts/render.mjs --list
node <skill-directory>/scripts/render.mjs <issue.json> <new-output.html>
```

脚本只校验并渲染选中模块，不做外部采集、模型编辑、发送或发布。输出文件已存在时拒绝覆盖；修订使用新文件名。HTML 使用本地样式，无外部脚本或跟踪；可选远程图片仍需要网络及使用依据。

检查内容、来源、计算及所需交互后，通过 DSH 原生 present 交付实际生成的文件。正文准确说明哪些资料和行为已验证。浏览器排版通过不代表事实已核验，HTML 生成不代表 WorkBuddy 安装或公网发布通过。
