# 按本期要求组装微刊

每次创建先确定读者、目的及本期模块清单。用户已指定模块时直接使用；只描述目的时，先提出精简组合，并按已有授权继续。缺少会实质改变结果的信息才提问。不默认加载十个模块，不要求按目录顺序完成其他业务工作。

创建入口是对话；不要求可视化编辑器。工单可以承载创建要求和上传资料，不引入额外的业务阶段流程。

## 十个可选模块

| ID | 模块 | 需要的信息 |
| --- | --- | --- |
| product | 产品展示 | 产品介绍、差异、可选图片和原页 |
| buyer-fit | 为什么推荐给你 | 买手实际客群、渠道、价格带与匹配理由 |
| opportunity | 产品机会点 | 观察信号、编辑判断、未验证假设 |
| launch | 新品首发 | 上市状态、时间依据、首批安排 |
| sales-history | 同类历史销售 | 同类对象、销售金额、时间、市场、渠道、口径与来源 |
| margin | 销售利润测算 | 同币种单件售价、成本、渠道费率与假设 |
| comparison | 同类产品对比 | 比较维度、逐项信息、可比性限制 |
| procurement | 采购条件 | 采购价、MOQ、交期等已知条款，未知项明确待确认 |
| sample | 样品申请 | 费用、条件及真实申请地址 |
| exclusive | 独家供应名额 | 确认状态、区域、渠道、期限、条件及供应方入口 |

一个模块可以放在整期层面，也可通过 product 标签属于某个产品。同一期不同产品可以使用不同组合；同一类型可重复出现，但块 id 唯一。blocks 数组的顺序就是版面顺序，未选模块不会生成。

## 获取和组织资料

资料入口是用户电脑工作区或通过工单上传到服务器的文件。只为选中模块读取必要资料，复用实际可用的原生文件／附件工具或工单附件接口。产品、图片、报价、成本及市场数据可以直接来自这些资料，不默认要求连接第三方 Spy Tool。

本地 Agent 可读取其可访问的用户工作区；云端 Agent 只有在文件已经上传、同步或通过实际本地连接可读时才能读取。不要把用户电脑路径当作云端文件。工单附件需绑定当前任务和实际可访问的文件；未配置接口时如实说明缺口，不声称已读取。

保留原文件名称、版本或读取时间、页码／表格位置；工单来源另保留工单号和附件标识。对外 HTML 不暴露内部绝对路径、私有附件地址或访问凭据，使用可披露的来源描述。额外网页研究按用户要求进行。不得声称已接入 FastMoss、Kalodata、AutoDS 或供应商库存，除非实际工具可用并成功读取。

事实绑定实际来源；已读取、用户提供、估算和排版示意分开标注。不得编造历史销售、买手偏好、未首发状态或供应名额。销售数据注明统计范围、GMV/净销售等口径和来源索引，估算不能升级为实际收入；同类历史不等于本品未来表现。

利润使用同币种、同税口径的单件输入。未知成本不能填 0；要么取得资料，要么把有依据的假设写明，要么省略该模块并说明原因。计算结果是所列成本下的贡献利润，不是净利润或回报保证。

独家模块只有真实供应方材料才能写 confirmed，这表示权益条件已确认，不表示买手已经锁定。slots 只是带 asOf 的名额快照。

交易动作由实际接入的 ERP 承担，包括样品订单、报价、采购及独家名额预留。CTA 使用已配置的 ERP 操作页面；工具操作则在用户已有授权范围内调用实际 ERP 接口。静态文件不能锁库存、收定金或确认合同。只有 ERP 返回明确成功及对应记录，才能声称交易或锁定成功；点击、提交申请、超时或本地状态不等于成功。未接入 ERP 时展示条件与待接入状态，不编造操作链接。sample 同理，不把费用未知写成免费。

已明确选中的模块如果资料不足，指出具体缺口，按用户要求补充、注明待确认或省略；不得静默填造内容。

## 生成文件

数据结构和字段说明见 `MODULES.md`。`templates/layout-preview.json` 是含十种模块的**排版示意**，其中金额和权益均为测试内容，不能作为真实商业稿。

使用原生文件工具创建本期 JSON，只写入所需 blocks；语言支持 zh / en，编辑正文使用目标读者语言。以本 skill 的 resourceBase 解析脚本路径：

```sh
node <skill-directory>/scripts/render.mjs --list
node <skill-directory>/scripts/render.mjs <issue.json> <new-output.html>
```

脚本只校验并渲染选中模块，不做外部采集、模型编辑、发送或发布。输出文件已存在时拒绝覆盖；修订使用新文件名。HTML 使用本地样式，无外部脚本或跟踪；可选远程图片仍需要网络及使用依据。

检查内容、来源、计算及所需交互后，通过 DSH 原生 present 交付实际生成的文件。正文准确说明哪些资料和行为已验证。浏览器排版通过不代表事实已核验，HTML 生成不代表 WorkBuddy 安装或公网发布通过。

## 可选简易 ERP 工具

若实际安装 mini-erp，可用 mini_erp_read 按当前工作区读取 product / offer / order；没有工具时不假定可用。绑定商品实时读取原产品库，传 quantity 可选择阶梯报价；quoteStatus=required 时价格为 null，应展示待询价，不能计算为零元。来源 unavailable 时先修复来源再生成。有效 unitPriceMinor 除以 100 才是 USD/EUR/GBP/CNY 单价，不能直接当作售价或利润。offer.availableSlots 是 asOf 时点的可用名额；登记的 source 仍需按任务核对原资料。

为本期商品调用 `mini_erp_read({entity: "supply", id: "商品ID", offerId: "明确选择的权益ID"})`，获得同一次只读快照；不需要权益时省略 offerId。将工具结果保存为任务工作区内的 snapshot.json，并按本期要求创建 selection.json，例如 `{"modules":["procurement","exclusive"],"language":"zh","timeZone":"Asia/Shanghai"}`。

```sh
node <skill-directory>/scripts/from-erp.mjs <snapshot.json> <selection.json> <new-blocks.json>
```

转换只支持 ERP 已有数据能够支撑的 product / procurement / exclusive，顺序按选择保留；不支持的模块或缺少选中权益时明确报错。将结果 blocks 合并进本期 JSON，内部 provenance 留在任务工作区，不随 HTML 发给买手。文本 source 不会被直接写进公开来源；经营者自由填写的产品名和权益条款仍需按本期披露范围审阅。

产品展示复用已读取的描述、SKU 编号与规格；图片按需从原库或工作区资料补充，不能把私有附件路径当作公开图片。采购模块保留报价数量、已录入 MOQ 与交期。采购条件保留未录入条款的缺口，金额从分转换为元。ERP 权益用 recorded 标记，仅表示已登记；拿到并核验真实供应方依据后才改成 confirmed。缺少零售价／成本或历史销售时不生成利润或销量模块。转换不会预留库存，不生成交易链接，不证明输入文件来自可信接口。

微刊生成只读取。用户已有交易授权时才使用 mini_erp_order 预留、确认或取消。绑定 SKU 下单前按实际数量重新读取报价，使用当前 revision 与 catalogRevision 作为 expectedRevision / expectedCatalogRevision。保存并复用 requestId 以处理不确定结果；读取回执的 current.status 和 expiresAt，不能把旧 receipt 当作现存名额。confirmed 表示本机 ERP 已确认订单，不代表已付款、发货或签署外部法律合同。当前插件没有买手门户或公网交易 URL，不能编造 actionUrl。
