# 市场研究取证

先明确要支持的具体判断，使用当前可用的原生搜索／网页读取工具或用户资料。
仅把实际读取的内容作为依据；没有网页访问能力时说明限制，不声称已核查。

## 来源与口径

| 来源 | 使用方式 |
| --- | --- |
| 官方统计、海关、法规原文、用户提供的后台记录 | 记录适用范围、日期和口径，不仅看发布机构 |
| 协会、展会、商业媒体和研究报告 | 作为佐证，检查方法及是否转引同一来源 |
| 平台商品页、卖家自述、商业目录 | 记录为展示或自述，不能当作已确认交易 |
| 论坛、社交内容、AI 摘要 | 用来找线索，进一步寻找原始来源 |

关键数字尽量交叉核对独立来源；只有一条时说明单来源。冲突数字并列其年份、币种、单位和统计范围，不直接取平均。
证据数量由问题决定，不以凑数量代替相关性。

## 检索与登记

可用检索式：<品类> importer <国家>、<品类> distributor、<品牌> reviews complaints。
法规优先找 EUR-Lex、Access2Markets、GOV.UK、FDA、FTC、CPSC、CBP 等适用官方入口；按目标市场语言补查。

需要证据表时使用 templates/sources.csv，记录网址、标题、发布者、发布时间、访问日期、主张与短引文。
引文保持原文，正文用来源编号关联；未知日期标明未知。证据表是普通文件，不依赖专用项目记录。

## 推断与估算

参数逐条给来源或标为假设。市场估算可用目标用户数 × 可达比例 × 购买频次 × 客单价，并说明区间。
市场规模不能直接推导企业收入；报价、MOQ、产能和认证不从行业平均值推给用户企业。
法规说明适用产品、主体与生效日期；无法确认时列出待核对的问题。
