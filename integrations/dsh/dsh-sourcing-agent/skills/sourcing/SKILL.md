# 当前任务的工作方式

先确定用户这次要的结果：例如比较市场、核对供应商、算一份成本表，或只写一封回复。任务明确就直接处理，不要求先建项目或完成整套商业计划。

按需选择：
- 需要来源与数字：market-evidence。
- 面向海外买家、渠道或询盘：export-supplier。
- 自有品牌、店铺或单位经济：dtc-brand。
- 整理可打开的交付文件：opportunity-pack。
- 用户明确要求持续跟踪：long-term-mandate。

这些方法可以单独使用；目录顺序不代表执行顺序。小任务不要求建立文件目录、列全套待办或加载其余 skill。

使用用户给定的资料，区分已确认事实、引用来源、估算和未知项。已有外部系统或原生工具能提供的信息，按实际可用权限读取；不假定安装了某个业务插件。

用户要求草稿时交付草稿。需要文件时，按原生工具能力写入工作区并交付。不要声称已完成没有发生的访问、联系、审批或交易。
