# DSH Service Billing

独立可选插件，依赖原生 DSH 身份、工具、附件和 Commerce 委托引用。不依赖 Mini ERP，不访问或迁移 ERP 数据库。

支持工厂固定委托费、渠道完整服务月账单，以及带实际附件凭据的人工收款／退款对账。金额从已审核委托推导；不向纯佣金委托收服务费，不生成 AI Credits 费用。

账单是内部服务对账单，不是税务发票。草稿需 Owner 确认才形成待收记录。无自动扣款、自动续订、发信或支付网关。退款冲回已收款、重新形成待收余额；它不自动减免服务费。账单减免和税务红字单尚未实现。

数据库默认位于 DSH_HOME/service-billing/billing.sqlite；可配置 dataDir。备份包括目录内数据库及 WAL。卸载保留数据库，恢复时使用兼容版本。本模块内的 provider + externalEventId 全工作区去重，不能将其宣称为其他账本或外部平台的全局对账。

月账期按合同开始日锚定，月末日期夹到该月最后一天，下一月恢复原锚定日。账期右边界不包含当天；仅生成已经开始的完整服务月，末期不足整月需另行约定，当前拒绝自动按比例收费。固定费同一委托只允许一张未作废账单，条款换版不重复收费。

使用入口为 Commerce Network → 业务委托 → 服务账单。未安装此插件时显示未连接，不建立备用存储。原生工具 service_billing_read 可读取，service_billing_propose 仅创建草稿；确认、作废及收退款登记均为 Owner 操作。已经确认的账单固定原条款版本，不因后续委托修订／撤销自动改写。
